Sobre

O Zombicide Spawn é um gerenciador de cartas de aparecimento projetado para otimizar suas partidas.

O algoritmo inteligente calcula as probabilidades de sorteio com base nas cartas físicas das expansões selecionadas. Ele agrupa tipos de inimigos e realiza os sorteios entre cada tipo independentemente, depois entre os inimigos do tipo sorteado e, por fim, a quantidade de inimigos. Ele também conta com um contador que segue a seguinte proporção:

Nível Necromantes Abominações
Base Incr Base Incr
Azul1%0,5%0%0,5%
Amarelo2%1%1%0,5%
Laranja3%1,5%2%1%
Vermelho4%1,5%3%1%

Configure sua partida escolhendo o cenário, mescle as expansões desejadas e controle o nível de perigo com facilidade. Selecione o modo padrão para seguir as regras básicas do manual ou o modo avançado para personalizar as chances dos inimigos individualmente.
